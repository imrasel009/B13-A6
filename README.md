# 🛒 DigiTools — Digital Tools Buying Website

> A modern platform where you can buy subscriptions for premium AI and digital tools to make your work more efficient and effortless.

---

## 📌 Description

**DigiTools** is a subscription-based digital marketplace where users can explore and purchase access to powerful AI tools. With a clean UI and seamless cart experience, buying your favorite tools has never been easier.

---


## 🛠️ Technology Used

| Technology | Purpose |
|---|---|
| ⚛️ React.js | Frontend framework |
| 🎨 Tailwind CSS | Utility-first styling |
| 🌼 DaisyUI | Tailwind component library |
| ⚡ JavaScript (ES6+) | Core logic |
| 🔔 React-Toastify | Toast notifications |
| 🎯 React Icons | Icon library |
| 📦 JSON | Product data storage |

---

## ✨ Key Features

- 🧰 **Multiple Product Options** — Browse different digital tools all in one section
- 🛒 **Cart Functionality** — Add multiple products to your cart at once
- ❌ **Remove Items** — Easily remove any product from your cart
- 💰 **Total Cost Summary** — See your selected products and total price at a glance
- ✅ **One-Click Purchase** — Proceed to payment with a single click
